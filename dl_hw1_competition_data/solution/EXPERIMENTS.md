## Диагностика после посылки 02

- Public 02 = 0.580 ≈ 01 = 0.579, хотя CV обещала +0.075. Симуляция на OOF-подвыборках размера public: P(прирост < 0.002) = 0.35% → это не шум.
- Сдвига признаков нет: KS p > 0.37 по всем датчикам; adversarial MLP train-vs-test AUC = 0.496; доля холостых 29% / 31%.
- Гипотеза: в test есть аномалии других типов, чем в train (supervised MLP их не знает). Проверка — проба 03: чистый автоэнкодер в A.
- Проба 03: AE public 0.294 ≈ CV 0.30 → AE переносится как есть, гипотеза «новые типы аномалий» **не подтверждена**.
- Кластеров-дублей среди аномалий нет (медиана расстояния до ближайшей аномалии 0.45 против 0.11 у норм) → утечки через соседей в CV нет.
- Группа simple: маленькие сети хуже на CV (0.70–0.73); сильная регуляризация (wd 1e-2, dropout 0.4) ≈ 02 и даёт почти то же ранжирование test (Spearman 0.94–0.996) → «переподстройка» не объясняет public.
- Ансамбль 4 разных MLP: 0.7506 (+0.004, в пределах шума) → по правилу ≥0.01 не берём.
- Группа more (база 02): шум на входе 0.05/0.1/0.2 → 0.747/0.743/0.725; focal γ=2/1 → 0.747/0.746; парная loss λ=1/0.3 → 0.739/0.746; ошибка AE как признаки → 0.72–0.73. Ничего не выходит за шум → потолок подхода ≈ 0.75 на CV.
- Независимый агент (свежий контекст): структуры в данных нет (кроме холостой строки), потолок у всех семейств моделей 0.67–0.75 (RF/бустинг/kNN — только для анализа), CV и public расходятся из-за трудной public-половины (~39 аномалий, P≈0.4%). Не помогли: asinh, SWA, mixup, PLE/PLR-эмбеддинги, исключение холостых, их перенос в конец. Помогает только обучение финала на 100% train (+~0.004).
- Решение: финал = 02 → 04 (то же + обучение на всём train) (лучше по CV на 0.07, в public не хуже 01).
